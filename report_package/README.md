# Hostel Mess Menu Optimizer — Overleaf package

Upload the contents of this folder to a new Overleaf project and compile `main.tex` with **pdfLaTeX**.

Included files:

- `main.tex` — complete Soft Computing project report
- `figures/` — report-ready PNG charts and workflow visual
- `generate_figures.py` — source used to create the figures from recorded project results

Before submission, replace `[To be added]` on the title page with the faculty/guide name. The report uses project artifacts already present in the repository; its results deliberately identify nutrition values and ratings as provisional.
